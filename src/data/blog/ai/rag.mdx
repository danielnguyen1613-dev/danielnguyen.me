## A minimal pipeline

1. Chunk source documents with overlap
2. Embed and store vectors with metadata filters
3. Retrieve top-k passages for the user query
4. Ground the model response in those passages
5. Return citations the user can verify

```ts
const passages = await store.similaritySearch(query, {
  k: 6,
  filter: { tenantId },
});

const answer = await generate({
  system: "Answer only from the provided passages.",
  passages,
  query,
});
```

## Failure modes worth testing

- Empty retrieval
- Conflicting passages
- Stale documents after a product change
- Prompt injection inside retrieved text

Build evaluation before polish.
